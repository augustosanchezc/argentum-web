- Debés tener al menos 13 años para crear una cuenta (o la edad mínima requerida por tu país).
- Sos responsable de mantener la seguridad de tu contraseña.
- No podés crear cuentas de manera automatizada (bots de registro).
- Cada persona puede tener una cuenta. Las cuentas múltiples para evadir sanciones están prohibidas.

## 4. Conducta

Está **prohibido:**
- Usar exploits, cheats, hacks o cualquier software que otorgue ventaja injusta.

- Intentar comprometer la seguridad del servidor o de otros jugadores.
